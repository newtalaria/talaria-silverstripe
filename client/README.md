# Browser SDK (npm)

Silverstripe loads [`@newtalaria/browser`](https://www.npmjs.com/package/@newtalaria/browser) from jsDelivr. Pin the version with `Talaria\SilverStripe\Config.browserSdkVersion` (default `0.5.3`).

Public pages set `publicAnalytics` when the project allows analytics. CMS admin does not. Setup is in the [Silverstripe guide](https://www.newtalaria.com/docs/sdk/silverstripe).
